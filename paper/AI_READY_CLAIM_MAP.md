# 一页研究逻辑（会后工作包 B）

> **用途**：回答师兄会上三连问——"AI ready 跟不 AI ready 的本质区别是什么？如果有好处，怎么通过实验指标体现？"——用通俗话写清"我们做什么、难在哪、改变了什么、希望看到什么、什么结果算不成立"。
> **完成判据（会议原文）**：师兄**无需逐个解释内部术语**，也能理解本文输入、操作、输出、对照和指标之间的对应关系。
> **纪律**：下面所有主张**都标为待检验**，不预设正结果。

## 一、五分钟能讲完的版本

**我们研究的问题**：真实医院的病历是**扫描 PDF**，不是数据库。要把它们变成"现成的 AI 能直接用"的东西，中间必须做一系列准备动作（把版面读成行、把单位统一、把来源标上、把时间排好、写清楚字段含义……）。**问题是：没人知道这些动作用处多大、哪一步值得做。**

**现有方式难在哪**：两条路都不好用——
- 不做准备，直接把扫描件里的文字塞给 AI：题目一难就不行（聚合类问题尤其），规模一大更是物理上放不下。
- 按治理规范做全套准备：**成本高、但没人量过收益**；而且现有"AI-ready"要么是人工打的等级分，要么比的是"已经结构化之后怎么排版"。

**我们改变什么**：把准备工作拆成**可以逐个加、逐个拿掉的几层**，让同一个 AI 在**只差一层**的两个版本上答同一批题。这样"这一层值多少"就变成一个可以直接读出来的数字，而不是一句主张。

**希望看到什么**：某一层（或多层）被加上时，AI 答对率明显上升；拿掉时明显下降。**并且换一个 AI、换一批题，这个方向还在。**

**什么结果说明收益不成立**：加不加这一层，AI 答对率没有差别；或者差别只在某一个模型/某一批题上出现（说明是模型偏好或题目偏差，不是数据的性质）；或者**加了层反而更差**（我们在"溯源与状态"这一层上已经见过一次——拿走它分数反而涨）。**这三种都照实写。**

## 二、输入 / 操作 / 输出 / 对照 / 指标 的对应

| 环节 | 我们的定义 | 现状 |
| --- | --- | --- |
| **输入** | 真实医院扫描 PDF（不含身份信息的受控环境切片） | 已定：984 病例 / 5,255 文档一批 |
| **操作（Harness）** | 一组可调用的准备动作：版面→行、单位归一、来源与状态、时间轴、机器说明书 | 已实现，可逐层开关；**哪几层最终进论文待定** |
| **上层编排（Agent）** | 拿准备好的数据去完成任务的消费者（一次调用 / 或多步调用，待定） | 目前只做"一次调用"这一种 |
| **输出** | 对临床问题的答案 + 出处 | 已实现 |
| **对照** | **待定**（会议明确要求先定对照）：候选是①不做准备的原始文本、②常规 ETL／只有格式统一、③全人工整理的数据 | **未定稿** |
| **指标** | **待定**：候选是做对率、费劲程度（token/轮次）、错答（含错否定）、该说不知道、核对时间 | 已有一版度量，但**会议未认可为最终指标** |
| **判定依据** | 待设计：机械答案 / 独立人工核对 / 模型辅助评价的组合 | **未定稿** |

## 四、我方的候选主张（**全部待检验，不是结论**）

| 候选主张 | 会怎样被推翻 | 现有素材 |
| --- | --- | --- |
| C1：把"字段含义/状态码/计数规则"写成机器说明书，能显著提高下游 AI 在计数与阈值类问题上的表现 | 换模型或换题目后差异消失；或差异只来自 token 数 | 3 个模型上方向一致（+5.1~+11.5 点），但**幅度差很大** |
| C2：把时间排成纵向轴（采集日期 + 按天聚合），能显著提高时间类问题 | 同上 | 3 个模型上方向一致（+8.9~+30.0 点） |
| C3：来源与状态字段（溯源）**不**提高答对率 | 换任务类型后出现正收益 | 3 个模型上均为负贡献或近零 |
| C4：不做准备时，聚合类问题在规模上"不是更贵，而是做不了" | 更长的上下文窗口出现 | 原文 12 例即超上下文；结构化可到 984 例但精度退化 |
| C5：多层级准备里，**层数本身不是卖点**，值钱的是特定的两三层 | 每层都被证明独立有效 | 目前只见两层有明显台阶 |

## 五、与"AI-ready 主流做法"的区别（一句话版）

> 别人回答的是"**怎样做才算准备好**"（治理规范、人工量表）或"**已经准备好之后怎么排版更好用**"（格式实验）。
> 我们回答的是"**从扫描件开始，每一步准备各值多少**"——用同一条数据链的逐层开关来量。

**这句话若不成立**（比如查到已有人做过同样的逐层归因），整篇论文的定位要改，不能硬写。
