# Benchmark 的板块划分与图组设计（2026-09-15）

依据：导师反馈"49 个问题是否都要作为列，需要归纳成几个板块"，并给了一份同事做的 benchmark 作为参照（胎儿超声心动图，7,422 题，Classification / Localization / Measurement 三板块）。

## 一、结论先说

**不要 49 列。** 参照那份 benchmark，它的主表也是归纳过的（Task type → Task → Metric → n），细项在附录。

我们的 49 个标量问题 + 16 张事件表，可以归纳成 **4 个任务家族 / 8 个内容板块**，
并且**天然对应参照那份的三板块结构**。

| 我们的家族 | 对应参照 | 判据 | 题量（每例） |

| **B 数值** | Measurement | `value_type` 为 number / integer | **6** |

## 六、测评指标（导师反馈：板块是输出，必须配指标）

### 按任务家族的指标

| 任务家族 | 输出形态 | 主要指标 | 辅助指标 |
| --- | --- | --- | --- |
| **A 分类** | 单选 coded / coded_string / coded_list / boolean | **Accuracy、Macro-F1** | **AUC**（二分类）、Cohen's κ、混淆矩阵 |
| **B 数值** | number / integer | **容差内正确率**（±0 / ±1 / ±3 / ±5%）、**MAE** | RMSE、相关系数 |
| **C 证据定位** | `source_refs` | **PCK@文档 / @页 / @行** | bbox IoU、MRR、引用有效率 |
| **D 事件抽取** | 16 张事件表 | **记录级 P / R / F1** | 字段级（值 / 单位 / 时间 / 来源）P/R/F1、漏项率、多项率 |
| **E 答案状态** | 9 类状态码 | **Macro-F1** | 混淆矩阵；3 类可机械核验状态的确切率 |
| 成本 | — | **token / 调用次数 / 延迟 / 费用** | 质量—成本曲线 |

### 8 个板块在出图时的角色

板块是**分组维度**，不是指标。每个板块报：`Accuracy` 与 `Macro-F1`（分类）；热力图为「模型 × 板块」的 Macro-F1。

### 由此产生的契约改动（必须做）

**`scalar_answers` 需要新增 `confidence` 字段（0–1）。**

原因：AUC 要求模型给出置信度或概率，而当前契约里只有 `event_tables` 有 `confidence`，`scalar_answers` 没有。
不加这个字段，AUC 这一列在物理上画不出来。

现有 9 个必填字段为：
`question_id / value / answer_status / effective_relative_day / source_refs / extraction_method / validation_status / conflicting_values / quality_flags`
→ 增加 `confidence` 后为 10 个。

### 必须单独报告的一列：标注一致率

两位复核人的角色不同（临床医生 vs 非临床初筛），实测：

| 项 | 数值 |
| --- | --- |
| 临床裁决完成率 | 1.00（51/51） |
| approved / needs_fix / unresolved | 28 / 20 / 3 |
| **跨角色一致率** | **28/51 = 55%** |

**主表必须按"医生一致"与"医生分歧"分层报 n 与指标**，否则几个百分点的系统差异会被标注噪声吞掉。
不缩范围，改为分层报告。

## 七、必须现在就定死的东西（导师说的"固定输入输出"）

1. **输入**：一个病例的脱敏文档集（`ocr_layout.json` 全集 + `result.json` 的 `category`）。
   **不含**答案、不含未脱敏原文、不含跨病例信息。
2. **输出**：`case_level_answer` —— `scalar_answers[]`（49 条，9 个必填字段）+ `event_tables{}`（16 表，每行 9 个必填字段）+ `evidence_index` + `conflicts` + `quality_summary`。
3. **评分**：每个家族一套指标，全部可脚本化。
4. **分层**：病例级划分，开发集与测试集按病例隔离。
