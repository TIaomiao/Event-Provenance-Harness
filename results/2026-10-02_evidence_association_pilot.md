### 两道 C 题先行核验

#### CASE-102 / C

**实际问什么。** 对 prompt 中给出的候选“记录—值—时间”组合返回 `supported`、`contradicted` 或 `insufficient`，并引用来源；不把报告时间当采集时间。候选哈希为 `1e6f3556cd89e341`，prompt 实际写入了一个无单位候选值和采集/报告引用 `DOC-013:L552` / `DOC-013:L555`，但没有把分析物标签写入 prompt；完整候选正文留在受控阅卷页。

**允许来源写什么。** 该病例模型可见范围是 DOC-013 全部 20 页。候选定位落在 DOC-013 第 2 页的 `DOC-013:L485-L488`：分析物行、观测值/单位行和参考区间行被机械抽取错位；`DOC-013:L552` 和 `L555` 分别明确标为采集时间和报告时间。也就是说，允许范围内并非缺资料：候选的“值”字段不是该分析物的观测值，且候选分析物没有在 prompt 中显式传给消费者。

**模型答什么。** B1、B1-V、B2 三组都返回 `contradicted`。三组都把 `DOC-013:L301` 的另一项目（Cr）作为反驳值；B1-V 还将无单位候选文本作为冲突理由，B2 返回了相同方向但没有解释。

**参考为什么这样判、现在如何判。** 旧参考由 `extract_hgb_candidates` / `independent_reference` 生成，因近邻数值/参考区间抽取和 `unit` 缺失而给出 `insufficient`。原页核验明确反驳了候选值，因此 v1 不再保留 `insufficient`，改作“候选构造错误；若按题目要求评估该完整候选，决定应为 `contradicted`”。三组模型的结论方向与 v1 方向一致，但证据没有指向候选分析物/观测行，属于来源关联错误；不能把它记成一条合格的“模型正确”证据。

**分项判读。** 值：候选值被原页反驳，参考构造错误；时间：采集/报告角色本身有明确来源，但没有和模型所引用的 Cr 行正确绑定；来源：三组均有可解析引用，但引用的是错误项目。最终：`参考构造错误 + 模型来源关联错误 + prompt 省略分析物导致题意不完整`，不是“资料不足”。

#### CASE-167 / C

**实际问什么。** 同一 C 契约，候选哈希为 `f590c156c98569bb`，prompt 写入一个无单位候选值和采集/报告引用 `DOC-012:L501` / `DOC-012:L503`；完整候选正文留在受控阅卷页。

**允许来源写什么。** DOC-012 第 3 页明确给出候选记录、HGB 项目、数值和单位（`DOC-012:L450-L453`），并在 `L501` / `L503` 明确给出采集/报告角色。全量 12 页检验文档中该候选的值与两个时间角色均有直接证据；资料并不不足。旧参考的 `unit=null` 是参考抽取漏掉独立单位行，不是原始资料缺单位。

**模型答什么。** B1 返回 `supported`；B1-V 与 B2 返回 `contradicted`。B2 的原回答明确把候选 prompt 中的 `unit=None` 与原文单位差异作为冲突理由；B1-V 只有 `contradicted` 字段，没有 explanation，原因保持未知。

**参考为什么这样判、现在如何判。** 旧参考把单位漏抽后标为 `insufficient`。但冻结题意是“记录—值—时间”三元组支持性，并未把单位缺失作为待判定的第四个组件；因此 v1 参考为 `supported`。B1 的值、时间和来源判断可接受；B2 的证据引用能够定位原文，但把参考字段缺失误当成候选事实被反驳，属于参考/表示与题意不一致；B1-V 没有给出足够解释，不能替它补出同一原因。

**分项判读。** 值：支持；时间：采集与报告角色均支持；来源：引用有效。最终：B1 为可接受正确；B1-V/B2 为“题意/参考表示冲突导致的错误判读”。若未来要把单位纳入 C，必须另定义任务并对三组统一改题、版本化，不能在本轮事后暗加要求。

**状态标注。** 已实现：18 条有效轨迹、受控回放页、旧键保留、v1 逐题原页核验。Demo only：B1-V 的提示级核验、B2 的固定 line-level preparation。推测：显式关联或有限补查会减少错误。还没做：正式参考键冻结、统一正式重评分、其余 4 个开发包、12 个留出包、B3/Jev。

**当前结论。** 本 pilot 暂时不能作为证据关联方法增益结果；它首先发现参考键和 C 题契约需要修正。最可靠的研究性事实是：在这两包资料内，值/时间/来源的错误可以由参考构造和字段范围制造，必须先把参考核验与任务契约分开。置信度：C-102/C-167 的原页局部判读为中高；跨病例和方法增益结论为低。还缺：用户在受控页确认两道 C 的题意是否把单位纳入，以及是否接受 B-CASE-102 将“最近”定义为检验报告内可排序的 HGB 记录。
