## 本轮范围与反例

已实现：纯离线、标准库评分器，12 条手工合成原始观测，独立声明的预期字段，刻意错误输出和自动测试。全部属于可公开给实现侧的合成开发材料。

最强反例：评分器对自己声明的答案得满分，只能检验评分算术；不能证明 B 能从 OCR 恢复这些事件。来源 ID 正确而值错误、同值同日但不同次采样、两个文档各自 day 0，都可以推翻只看字段或日期一致的评价。

边界：参考答案已独立核对、输入按本文件的 C 开发序列化提供时，才能解释计分。当前合成金答案由 C 手工声明，尚无第二位人工独立复核；不称临床金标准或独立测试集。替代解释包括更强上游输入、更高预算和人为简化来源关系。

结论：本轮是评分器开发自检，不是方法实验；真实模型对照、真实开发参考集、独立测试、临床效果均还没做。

## C 开发序列化（供 A/B 核对，未升级为共享 schema）

最外层：`protocol`、`observations`，可选 `event_groups`、`cost`。
共享观测字段仍为 `observation_id/case_token/item/value/unit/time_assertions/source_refs`。
`value` 与 `unit` 当前均为字符串。相对日只接收整数；小时、区间、精度需要下一版定义。

每条时间断言在此开发实现中具体展开为：

```json
{"role":"sampling","relative_day":0,"coordinate_id":"C1",
 "date_ref":"d1s","role_ref":"ls-t1","scope_ref":"t1","binding_status":"explicit"}
```

无采样依据必须保留一条 `role=sampling`，日期、坐标和三个引用为 null，状态为 unknown 或 unresolved。缺字段属于格式错误；不等同模型明确弃答。实际已知日期但角色/行归属未决时，另外保留相应断言。

本开发层 `source_refs` 只放原始行 evidence ID；日期、角色、范围引用放对应时间断言内。不同位置的同名字标签用不同稳定 ID；两行共享同一表头时共享该表头 ID。ID 存在、类型正确、支持断言是三个不同条件。

原始观测行和最终事件是两层：副本行不从观测层删除。`event_groups` 是 C 的临时开发附加字段，包含归为同一次事件的原始行 ID 集合；不能让 B 为此擅改共享协议。归并后的最终事件表必须先由 B/A 明确适配方式，不能直接把删掉副本行的最终事件表当作原始观测层输入。

## 对齐与评分

1. 参考答案先验检查：版本、唯一观测 ID、证据类型、病例范围、行证据唯一归属。参考错误拒绝运行。
2. 提交格式错误：整次记 invalid_output，TP=0、FN=全部参考观测；能数清提交行时记录 FP；仍记录调用成本。不得跳过坏行后只评价成功部分。
3. 候选匹配只用病例和原始行来源交集，不用值、时间或模型生成的 observation_id。最大基数一对一匹配，排序固定；每条参考最多计一次。多来源落到多条参考时记 ambiguous_source_predictions，不给其字段诊断分。
4. 分别计 item+value、unit、sampling_time、all_time_assertions、source_support。字段分母是全部参考行，另报 aligned_count；不把只对齐成功的子集准确率伪装成总体准确率。
5. 值用十进制精确比较：4.2 与 4.200 等价；不做数值容差、单位换算、同义词或临床推断。`<4.2` 与 `4.2` 不等价。
6. 时间断言比较 role、relative_day、coordinate_id、binding_status 的多重集合；日期错角色、跨坐标相等、丢掉冲突、unknown/unresolved 混用均失分。
7. 来源支持要求值/单位被对应参考行支持，来源行集合一致，且每条日期断言的日期/角色/范围证据与独立参考一致。存在但支持别条事实的 ID 不得分。当前是严格参考支持集；等价替代证据须人工补入下一版支持契约，不做 LLM 语义裁判。
8. 主指标 joint = 值/单位 + sampling + 来源支持；full_record 额外要求所有角色断言完整。只漏报告时间但采样完整时，joint 可不降，full_record 必须降。因此两者必须同时展示，不能只挑高分指标。
9. 严格 TP 为满足完整条件的一对一最大匹配数；FP=P−TP，FN=G−TP，F1=2TP/(P+G)。空分母为 null。时间或值错误既有严格 FP/FN，又有字段诊断；这些计数不能相加当互斥错误总数。missing_observations/extra_observations 指来源层未对齐数量，区别于严格 FP/FN。
10. 副本/复测单独按预先声明的身份对计 false_merge、false_split 和 missing_decision。同值同日不自动产生 same 真值。未决关系若被强行归为同组或不同组，记 unsupported_resolution。未提交组或缺少观测时记覆盖缺口。临时分组字段尚不能正面表达“已审但未决”，本版不给该类正确分，等待 A 定版关系接口。

## 成本与失败

`cost.attempts` 每次真实尝试一行：唯一 attempt_id、status(success/failed/timeout)、input_tokens、output_tokens、amount；所有重试和失败都计入。顶层 wall_seconds 是任务墙钟时长，不是并发调用耗时求和；currency 统一为 USD/CNY/EUR，汇率换算另行记录。

未记录为 null/not_recorded，部分缺失为 partial，禁止填 0。只有明确的空调用清单才可记录调用数 0；计数负数、重复 attempt_id 等为 invalid。模型名、版本、预算、缓存 token 和供应商用量字段等扩展项待 A 定版。测试里的费用数字是合成记账例子，不是实际费用。

匿名结果只返回计数、比率、版本、固定错误码和成本汇总，不输出患者内容、参考值、来源 ID、原始模型响应或原始路径。

## 需要 A 对齐的字段与决策

| 项目 | 本轮 C 开发取法 | A 需定版内容 |
| --- | --- | --- |
| 版本入口 | 用户确认以本地 v0.3 为准 | 何时将远端旧入口统一指向当前协议 |
| 行层/事件层 | 原始行保留，身份分组另评 | B 提交哪一层，副本与规范事件映射字段 |
| 时间序列化 | relative_day、date_ref、role_ref、scope_ref | 共享字段精确名称、日期粒度/区间、状态组合、可选性 |
| 来源结构 | source_refs 为行 ID 列表 | 是否使用带类型对象；bbox/源版本解析器与替代支持集 |
| 表头范围 | 独立 scope_ref，由参考给定正确关系 | row_id 列表、表格/页范围、跨页证据的 schema |
| 匹配冻结 | 按病例/行锚点一对一；模糊匹配不获诊断分 | 对引错来源与无来源但正确值如何单独归因；冻结版本/哈希 |
| 身份关系 | event_groups 临时开发字段 | same/different/unresolved 显式关系及组到观测映射 |
| 指标范围 | joint 与 full_record 同报 | 主终点、缺失/额外、宏平均、置信区间与分层方案 |
| 值和单位 | 精确十进制，单位字面相同 | 单位转换、同义项目、比较符、数值容差是否启用 |
| 成本账本 | 尝试级 token/失败/耗时/费用 | 模型版本、缓存 token、预算、重试上限、价格版本 |
| 参考集 | 先开发 10–20 条，独立测试另分 | 病例划分、人工核对者、冻结时点、查询任务范围 |

这些待定项不阻塞本轮合成评分器自检，但在 B 实际输出联调或真实实验前必须裁定。C 不修改 B 的内部代码或共享研究卡。

## 后续真实参考与隔离

按 `REVIEW_TEMPLATE.md` 准备 10–20 条开发事件；本轮只提供空模板，未抽取真实参考答案。真实原文、OCR、bbox 对应原图、路径映射、参考答案与逐题评分均留在受控环境，父目录 0700、文件 0600、Git 忽略规则及有效访问权限需要在创建时核验。

独立测试按病例划分，开发病例及其副本/近重复不能进入独立集；冻结输入、参考和评分器版本后再运行。C 与独立核对者持有测试答案，实现侧只拿冻结前的合成/开发材料。共享账号下 chmod 不能实现角色间隔离，正式独立测试需要独立授权身份/存储或有效 ACL；在隔离边界落实前，不在共享运行目录创建独立测试答案。独立答案和逐题诊断不得回流给 B 调参；最终只发布允许的聚合报告，后续改方法须使用新保留集或明确标记重复使用。
