## 2026-09-05 / DSH 通读 DataSpace（arXiv 2608.03451v1，本地 PDF 24 页）

- **我的理解**：DataSpace 不是医学论文（410 题中金融/宏观占 88.5%，47 题临床来自 EHRSQL），但任务形态与我们的方向同构：异构证据散布 + 完整表格输出 + 确定性评估 + 运行时不见参考答案。核心发现：固定 backbone 时 harness 差 15.36 分；136 个失败中 56.6% 属"输出契约误解/材料化错"（M1 44.1%），仅 3 个是选错来源；文档渲染采用 cell→span 对齐 + 锚点 + NULL_POLICY，Task 310 把 LABEVENTS 行渲染成临床台账文档，与"检验记录事件抽取"同构。
- **待确认**：仓库与 KDD Cup 2026 版本是否与 v1 一致；60 题公开参考答案口径；我们的 A/B 里"组织证据"算不算它 harness 对照的一个子情形（我认为不算：它是整系统对比，我们是单机制干预，互补）。
- **对研究卡的建议**：①评分器抄它的规范化规则（列对齐、类型/精度/单位、行序、重复行多集）但改行级分层计分；②合成试卷改用"事实接地渲染"法（真值由构造保证，人审渲染保真）；③错误分类预注册 Q/D/E/G/C/M/T + OCR/时间接口两类；④成本按 token/动作/延迟/价格四维报告。详细版见阅读包 `03_研究卡与笔记\02_DataSpace深读与两月阅读计划.md`。

## 2026-09-08 / DSH 对照 RESEARCH_IDEA_HANDOFF + 用户阅读卡答案

- **我的理解**：交接文档与我的 DataSpace 深读一致，且理顺了分工（工程对话管接口与执行，本对话管文献与主张）。最有用的三件：①一句话主张（显式文档/时间组织是否降低值—时间—来源错配并保持召回）；②下一轮只读四问；③一页技术规格模板 = 给师兄的汇报载体。B 已完成时间适配 v0.3.1（2 例 26 文档、952 候选），但日期角色与检验行绑定未完成，真实模型对照未开始 → 合成最小闭环是当前唯一可立即推进的路径。
- **对 DataSpace 的判断（答复交接四问之一）**：可复用的不是 builder 全量（跨语言迁移、模态路由、视频与我们无关），而是评估协议（§4.5 规范化规则）、对照结构（§6.1 固定一个变一个）、失败分类（§6.5 Q/D/E/G/C/M/T）、渲染保真规则（A.3.2 锚点/无竞争值/NULL 显式，仅用于造合成材料）。
- **用户阅读卡四题对照结论**：①输出是"完整表格"而非"回答问题"；②两种受控对照：固定 harness 变 backbone / 固定 backbone 变 harness（harness=Codex/Claude Code 这类 agent 系统，不是"标准"）；③判定=格式等价（列可换序、表头不计）+ 与 gold 全表一致，二元无部分分，运行时不可见 gold；④要改的环节研究卡已定义（A 直接抽 vs B 先按文档+时间组织再合并），DataSpace 只提供"怎么比才公平、错在哪怎么数"。
- **对研究卡的建议**：把"本轮产物"排序成最小闭环 P0–P4（任务定义一页纸 → 3 例合成材料 → stub 冒烟 → 评分器 v0.1 → 错误预注册），每件都可单独向师兄汇报；builder-lite 推迟到真实切片可用之后。
- **待确认**：合成材料上调用真实模型（费用/供应商）的授权；3 份检验文档中 1 份无合格日期候选的处理。

- **我的理解**：摘要级检索确认了缺口——没有一篇公开工作直接做"观测级五要素（item/value/unit/event_time/evidence_id）绑定 + 跨文档重复观测保留不去重 + 相对日/unknown 语义 + 直接抽 vs 先组织再抽的消融"。最近邻居分三支：编排对比（HealthFlow/MedAgentBoard）、跨来源要素交叉引用（CliBench, arXiv:2406.09923，开源）、临床 IE 标准化框架（ClinBench, NeurIPS 2025 D&B——是否含化验观测维度未能验证，恰可作缺口证据）；Irvin 2020（ACL WS）是相对时间锚定的经典参照。
