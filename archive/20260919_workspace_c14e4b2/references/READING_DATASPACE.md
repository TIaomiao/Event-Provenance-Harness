# DataSpace 第一轮阅读卡：约 50 分钟

本轮目标：能解释一道任务给什么、交什么、怎样比较 harness，并据此修改自己的研究卡。

| 时间 | 阅读位置 | 留下一句话 |
| --- | --- | --- |
| 0–10 分钟 | 论文摘要与任务定义，优先找输入输出例子 | 一道任务是“问题 + 什么输入 → 什么输出” |
| 10–25 分钟 | baseline README 的任务合同与工具列表 | 模型有哪些工具，流程由什么控制 |
| 25–40 分钟 | 论文同模型 harness 对照表、evaluation README | 固定了什么、变化了什么、怎样算做对 |
| 40–50 分钟 | 回到 RESEARCH_CARD.md 与自己的合成例子 | 我想借其中哪个设计来做第一轮比较 |

入口：

- [论文](https://arxiv.org/html/2608.03451v1)
- [baseline](https://github.com/HKUSTDial/DataSpace/blob/main/baseline/README.md)
- [评分说明](https://github.com/HKUSTDial/DataSpace/blob/main/evaluation/README.md)

## 阅读后自己先填四句

1. 它给 Agent 的输入是：____；要求交付：____。
2. 它比较不同 harness 时固定：____；允许变化：____。
3. 它判定正确的方法是：____；Agent 运行时能否看到参考答案：____。
4. 我第一轮想改变的一个处理环节是：____；准备看____是否改变。

第一轮读完后把答案与不理解的句子带回总控或 DSH，先确认理解再讨论借鉴。HealthFlow 放在理解 DataSpace 的任务与比较方式之后读。

## 已核验的提示，供填写后核对

官方任务为问题加异构工作区，输出完整表格；baseline 使用通用工具的 ReAct 循环。论文固定模型比较多个 harness，统一环境与时限，并不意味着所有内部动作数相同。格式检查和答案正确性评分分开，运行时不给参考答案反馈。

以上来自此前原文与官方仓库核查，未复跑实验。阅读时遇到版本变化，记录具体来源并向总控提出更新。
