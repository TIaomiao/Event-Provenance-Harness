## C1｜证据会计：答案是「计数」而不是「值」

**标题（草稿）**：Counting Is the Answer: Event-Level Evidence Accounting for Longitudinal Questions over Real-World Clinical PDFs

### 重新定义的入口

现有评测把临床文档 AI 当成抽取：抽出值、抽出时间、给值配引用。C1 把输出对象改成**证据账本**：
对任一纵向问题，系统须同时给出（a）答案值、（b）该答案由**多少个独立现实事件**支撑（分母）、（c）每个事件挂到哪些文档/页/哪个时间字段（见证），以及（d）当身份不可判定时的 `suspend` 类别。
值对、引用对，分母仍可错——而分母错不会被任何值级或引用级指标暴露。

### Motivation（1–2 条）

1. **引用的数量本身就是错的。** 已核验的 ACIE（arXiv 2606.19602）给出 hallucinated reference 0.0%、missing reference 1.2%，说明「引用有没有、指得对不对」已不是主要错误源；而事实 C 表明本数据的两套命名体系精确命中 0/50，叙述里每一条检验引用都无法凭字符串钉回源报告页。于是「这位患者这次住院做了几次血常规」这类问题的**分母在第一步就已经错了**，而每一句引用可能完美。
2. **合并方向与既有去重文献相反。** 文档级近重复（MinHash/LSH，Gabriel 2018，PMID 29679685）与其它领域的事件级去重（疫苗剂量级去重、vigiMatch、测序 UMI）语义都是「删重复」；而事实 A 的 11 页 → 2 次采血要求系统**保留全部页、但把它们归到同一事件**，同时**不把真实复测并成一次**。误合并与误拆分的临床代价不对称，这一点在任何现有指标里都不存在。

### 三个创新点（相互支撑）

1. **对象与前缀**：把「证据计数」形式化为可评测对象——输出 =（值，事件划分，每事件的见证绑定，`suspend`），指标 = 计数误差、划分一致性（pairwise / VI）、**误合并/误拆分混淆矩阵**（代价不对称）、以及 `suspend` 的正确性。它定义②③要测量的东西。
2. **机制**：一个**不允许使用名称**的身份判定器——在同一采集时间簇、检测号、标本、病区/床号、文档类型、页序这些页级证据上做受约束划分 + 弃答。附带一个可报告的定量结论：哪些页级字段是**识别性**的、哪些是装饰性的，以及名称相似度与文档级近重复信号在该判定上的信息量为零。它是①唯一要测的对象。
3. **可扩展金标准 + 对抗分层**：金标准由采集时间元数据自动导出（事实 A 推广到 n200 池），并叠加三个受控分层——（i）遮蔽采集时间，强制从其它页级字段推断；（ii）注入合成复测（把某一页的采集时间平移若干分钟/小时），检验「同一次采血」与「真实复测」是否被分开；（iii）注入文档级近重复。分层是②的否证装置，同时给出「金标准自动导出 → 评测可无标注扩张」的规模论证。

### 绑定资产

n200 池的 `ocr_layout.json`（bbox 级）+ 检验报告页脚四时间字段 + 病程记录正文引用 + `redaction_hits`。不需要新数据、不需要新标注、不需要大算力。

### 最小否证测试与放弃判据（按顺序执行，任一成立即放弃或改题）

- **G1｜泄漏检查（先做，最便宜）**：只用文件名、目录顺序、PDF 页序做分组，与采集时间金标准比。若文件名或页序已编码采集事件 → 任务塌缩成读文件名，**放弃**。
- **G2｜尺度检查**：在 n200 池上统计「每病例事件数」与「每事件页数」分布。若绝大多数文档 1 文档 = 1 事件（分母问题不存在）→ **放弃**。
- **G3｜叙述计数偏差检查**：从病程记录抽 `[组合名][日期]` 引用，与采集时间事件数逐例比，统计偏差率。若偏差率≈0（叙述计数本来就对）→ **放弃**（这正是事实 B 的同类否证）。
- **G4｜遮蔽后差分检查**：遮蔽采集时间后重跑前沿模型。若模型仍达 ≈ 金标准划分且弃答正确率合理 → 机制无差分，**放弃**。

### 为什么不是增量

不是「多抽一个字段」，而是换掉答案对象：新增的评测对象是**计数的正确性**，其错误在值级与引用级指标下不可见。它与名称归一化路线不重合——事实 C 的 0/50 已在起点宣告字符串路线失效；与文档级去重不重合——目标方向相反（合并归并 vs 删除）。C1 的主语是「证据单位」，不是 agent 层或架构层，因此不会落入「多套一层」的形态。

### 占位对照（必须逐字核读后才能动笔）

- arXiv 2608.22062（MedEventGraph-RAG，证据可采契约 + occurrence binding，摘要已列 "repeated documentation"）：它验证**给定事件之间**的关系并做证据筛选；C1 产出的是**从多文档证据恢复事件划分与分母**，且评测在真实扫描 PDF 的页级结构上。已核验的重叠边界必须逐字确认。
- arXiv 2609.13062（Anchoring Clinical Events in Time，UID-Preserving）：**「UID 保留」意味着身份已给定**；C1 处理的正是身份**未被给定**（事实 D：无行级标识）的设定。这一句是 C1 能否成立的关键，必须读原文确认 UID 的作用域。
- arXiv 2607.22954（EHR 文档不一致检测）：它检测不一致，**不产出引用—源报告行的对应关系**；C1 把该对应关系本身作为评测对象。
- 2609.09218 的 dedup (T3) 是通用套件中的一格，无页级结构、无临床代价不对称。

### 风险

文件名/页序泄漏（G1 必须先跑）；n200 池内「事件被多文档重复记录」的密度可能不足（G2）；审稿人可能读作 entity resolution 的实例，辩护只能靠输入假设（0/50、页级仅有）与代价不对称，不能靠术语；2608.22062 与 2609.13062 的摘要级重叠判断未经全文核实。

## C2｜擦除之后仍可审计：把治理状态变成证据模型里的变量

**标题（草稿）**：Auditability Under Erasure: Identity Evidence That Survives Lawful De-identification in Real Clinical PDFs

### 重新定义的入口

临床 AI 的现行做法把脱敏当作**前置常量**：先脱敏，再在已脱敏数据上谈准确率。C2 把它变成**独立变量与目标函数**：身份类证据（检测号、标本、病区/床号、时间戳、患者标识）恰恰是被脱敏流程删除或涂抹的那些字段，因此「结论是否可被第三方复核」不是模型属性，而是**保留策略属性**。评测目标从准确率改为两个目标：隐私风险 vs 结论可审计性，并要求系统在证据被合法擦除后**悬置而非猜测**。

### Motivation（1–2 条）

1. **事实 E 的两个方向同时成立**：33/40 含 6+ 位数字的 OCR 记录落在脱敏区域内（看起来清理干净了），但身份判定赖以进行的页级字段与患者标识在物理上同处一个区域——清理的同时也在破坏可审计性。这个张力目前是未被量化的：ComplianceGPT（IEEE 11588232）做的是合规流程自动化本身，而不是「脱敏覆盖度 → 下游结论可测偏差」。
2. **脱敏是**可**被逐 bbox 复现的**：本资产已有 `redaction_hits`（带 bbox、entity_type、rule），意味着可以**在不改生产流程的前提下**按 bbox 重放与增强脱敏，测量结论翻转率。这把「治理」从合规叙事变成可做实验的自变量。

### 三个创新点（相互支撑）

1. **形式化**：给出证据字段的分类学与**存活谓词**（在给定 `redaction_hits` 下字段是否仍可读、是否仍具识别性），并把「结论可审计性」定义为：该结论的最小见证在擦除后是否仍可定位。它定义②要测的量，并让③有优化目标。
2. **测量**：脱敏重放实验——在真实 `redaction_hits` 之上按强度递增（现状 → 逐字段消融 → 更强策略）重放，测每个字段的**存活曲线**、结论翻转率与 `suspend` 率；同时实测「被擦除时系统是猜还是悬置」。它给①提供数值、给③提供选择空间。
3. **设计规则与产物**：算出**最小保留配置**（为保 X% 可审计性必须保留/代理化哪些字段）及其隐私代价，落成一条可执行的治理制品，接上现有 `api_ready` 状态机与复核控制台。它是①的目标与②的数据的合成结果；若不存在这样的配置，则本候选的产出是**不可能性结论**（同样是有价值的负结果）。

### 绑定资产

`redaction_hits`（bbox/entity_type/rule）、人工隐私复核工单、`api_ready` 状态机、治理控制台、`ocr_layout.json` 的 bbox 对齐能力。

### 最小否证测试与放弃判据

- **G1｜字段存活普查**：对 n200 池的 `redaction_hits` 与 `ocr_layout.json` 做 bbox 相交，统计「采集时间 / 检测号 / 标本 / 病区床号 / 患者标识」各自的存活率。若采集时间从不被擦除且足以单独支撑身份判定 → 张力只剩单点，需要立刻评估 G2 是否还能立住。
- **G2｜不变性检查**：在重放的不同脱敏强度下测结论翻转率。若翻转率≈0（结论对擦除完全不变）→ **放弃**（无张力）。
- **G3｜退化检查**：若结论翻转呈全有全无（任何配置下要么全保住要么全丢）→ 帕累托前沿退化为一点；此时改题为不可能性结论，或放弃。
- **G4｜授权检查**：模拟增强脱敏是否被授权（现有授权是受控环境只读 + 不重启服务 + 不外发）。若不允许在真实数据上做任何重放 → **阻塞**，本候选不能启动。

### 为什么不是增量

它改的是**目标函数**：不是把脱敏做得更好（那是合规自动化，已被占位），而是把「治理状态如何改变结论的有效性」作为被测量的量，产出是可执行的保留策略而不是模型指标。它也不可能靠加字段/加模块完成——被优化的对象本身就是「保留哪些字段」。

### 占位对照

ComplianceGPT（IEEE 11588232，合规自动化，不量化下游偏差）；arXiv 2609.02127（类型化 provenance，区分「被存储」与「被支持」，对象是 agent 自身断言强度，不含擦除）；arXiv 2605.21949 / GAVEL（断言放行与证据契约，均以证据完整为前提）；**新发现需核验：arXiv 2604.17114 "The Provenance Gap in Clinical AI: Evidence-Traceable Temporal Knowledge Graphs for Rare Disease Reasoning"**——本轮检索新出现，未在既有占位清单内，必须先读，若其已覆盖「证据可追溯性在临床 AI 中的缺口」这一提法，C2 的立论需要重写。

### 风险

授权风险最高（G4 可能直接阻塞）；前沿可能退化为一点（G3）；与 2609.02127 的「断言强度」提法相邻，必须把对象精确限定为**由治理流程诱发的、可逐 bbox 复现的擦除**，而非随机遮蔽；赛道选择存在内部矛盾（面板记录 D&B 要求数据无需私人请求即可访问，而另一轮调研记录 D&B CFP 含 "even if the dataset itself cannot be shared" 条款）——动笔前必须用官方 CFP 原文裁定。

## C3｜可判定性层级与受控降级：在已饱和的任务上制造方法差分

**标题（草稿）**：Decidability Ladders: Manufacturing Method Differential Where Clinical Document Tasks Are Already Saturated

### 重新定义的入口

临床文档 AI 的评测困局是：凡是答案在数据中显式存在的题目都已被前沿模型打满（事实 B：10/10，最便宜模型同样全对），而继续加题目只是重复。C3 不做新数据集，而是给**测量本身**定一套构造规则：（i）每个条目必须标注回答它所需的**证据显式度层级**；（ii）金标准由文档元数据导出，因而可在无标注下扩张；（iii）难度由**受控地移走显式信号**制造，而不是由增加问题制造——这样金标准在构造上仍然有效，而方法差分重新出现。

### Motivation（1–2 条）

1. 社区自己承认了这一困局：arXiv 2606.26158（benchmark 饱和之后怎么办）、arXiv 2609.09218（双重测量混淆、去 scaffold、不要只看均值）、Information Fusion 2026（解法可能已进入训练数据）。这三篇给出诊断，但没有给出**当金标准可从元数据自动导出时，怎样让评测重新产生差分**的构造方法。
2. 本资产提供了一次罕见的现成机会：采集时间元数据使金标准可零标注导出（事实 A），于是可以**只移走信号、不改变真值**地造难度——这正是受控降级的前提条件，公开数据上很难同时具备。

### 三个创新点（相互支撑）

1. **构造概念（层级）**：可判定性层级 L0–L4 —— L0 答案字段显式存在（事实 B 的 10/10 全在这一层）；L1 需要页级→行级的时间归属（事实 D）；L2 需要跨命名体系的引用落地（事实 C 的 0/50）；L3 需要身份在擦除后仍可判定（事实 E）；L4 不可判定，正确答案是 `suspend`。层级给②的降级算子定义目标，给③的计分定义条件。
2. **构造方法（自动金标准 + 降级算子）**：金标准由元数据导出；降级算子按层级定义（遮蔽时间字段、破坏页级标识唯一性、打散页序与文档类型混排、注入复测扰动、增强擦除），每个算子必须满足两条有效性约束：**保持真值不变**且**保持文档自然**（附一个人工可查的伪迹检查：若降级后的文档能被一眼看出是改过的，该条目作废）。它是①的层的实现，也是③的被测材料。
3. **评测协议**：层级条件计分 + 弃答计分 + 去 scaffold 对照 + 可靠性区间（不报单点均值），并附一份**捷径检查表**（文件名、页序、答案长度先验、字段缺省模式），任何一条命中即判定该结果无效。它让①②产生的差异可被判为真差异。

### 绑定资产

`ocr_layout.json`、页脚四时间字段、病程记录引用、`redaction_hits`、n200 池的分层结构（20 类文档、每例 5–18 份 PDF）。

### 最小否证测试与放弃判据

- **G1｜天花板块检查（最优先，成本 < $0.2）**：在 DOC-013 上遮蔽采集时间，观察模型是否仍然全对。若遮蔽后仍全对 → L1 层无差分，继续测 L2（把叙述引用给模型，要求钉回源报告页）与 L3；若 L1–L3 全部无差分 → **层级无语别力，C3 放弃**（这正是事实 B 的直接外推，发生概率不低，必须最先测）。
- **G2｜伪迹检查**：把降级后的文档交给模型/人判断「是否被人工改过」。若都能识别 → 降级无效，条目作废；若作废率过高 → 放弃该算子。
- **G3｜金标准可导出性检查**：除采集时间簇之外，还能否为别的查询族导出零标注金标准。若只有一族 → 规模主张塌缩，降级为小案例研究。
- **G4｜层级可机械指派检查**：层级标注能否由脚本判定。若必须人判 → 不可规模化，**放弃**。

### 为什么不是增量

它不新增模型、不新增字段、不新增 agent 层；它改的是**评测构造规则**本身，并且给出的可检验命题是「受控降级能在金标准不变的前提下重新产生方法差分」。它必须承受「又一个 benchmark」的质疑，因此正文必须写成测量与构造效度论证（层级、算子有效性、捷径检查表），而不是数据集介绍。

### 占位对照
