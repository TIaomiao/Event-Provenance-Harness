# 第一轮 EHR Harness 研究协作

本目录保存研究交接、合成任务设计与匿名进展。先读 START_HERE.md，再按角色读对应文件。

- 总控 A 维护 CONTEXT.md、RESEARCH_CARD.md 和协议版本，负责将讨论结论整理为可执行安排。
- 原型 B 维护实现代码及实现状态；评测 C 维护评分代码及评测状态。各自只修改归属自己的文件。
- 本地 DSH 用于读论文、讨论和审查；提议写入 discussion_notes.md，由 A 汇入正式研究卡。DSH 不直接改 B/C 代码或正式协议。
- 研究卡带有 draft 状态时可做接口调查、合成用例与设计讨论；正式实验需使用明确的协议版本与具体模型/数据授权范围。
- 本目录和跨端交接文件仅保存非敏感研究设计、公开参考链接、合成例子与匿名统计；患者正文、真实身份映射、凭据、模型原始响应与人工标注内容留在获准的受控位置。
- 临床正确性与结构格式校验分别报告，参考答案不由待测系统自动生成后直接充当真值。
- B/C 每次工作单元后更新自己的状态文件，写清所用协议、完成事项、验证证据、阻塞与下一步。代码完成与实验效果分开描述。

父目录适用规则继续生效；本文件仅规定本研究目录内的分工。
