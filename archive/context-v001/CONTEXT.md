# 当前研究上下文

版本：context-v001。来源：用户 2026-09-05 讨论、此前只读项目核查与公开论文阅读。

## 目标

近期首要任务是推进第一篇面向计算机会议的论文，下次与师兄交流时有任务定义、真实对照结果和错误分析可汇报。用户为大二、首次开展论文研究，希望通过小型实验理解研究过程。

师兄提供 idea 与参考，用户负责具体推进。Harness 是候选定位；先围绕真实 EHR 上的数据组织、模型调用和结果检查做实验。会议备选按用户转述记为 MICAD，名称、届次和日期未核验。

## 可复用基础

- 既有 OCR 文字、页码、bbox 与置信度，以及本地脱敏和人工复核流程。
- 病例级标准试卷、纵向事件表、统一缺失状态与 source_refs。
- 模型请求契约、任务构建、输出校验和响应接收代码入口。
- 医生反馈可作为定义与错误线索；第一轮优先选择可对照原文明示证据核对的任务。

以上为此前核查的文档和源码入口事实，不代表本轮模型实验已完成，也不代表已有完整临床金标准。新开任务应只读核对自己需要复用的接口是否变化。

## 第一轮工作方式

用户本轮已确认从重复检验与时间匹配开始；模型直接抽取与分组证据组织的具体比较方式为总控提出的 v0.1 草案。

1. 与用户确定一页研究卡。
2. B/C 共享固定输入输出协议，分别完成实现与评测。
3. 在小型开发集上观察真实错误，只改变一个主要处理环节。
4. 用户亲自看代表例子、解释结果，再安排下一轮。

首轮只做原文明示事实的提取与关联，规模用于流程调试。最终论文评价集、任务覆盖和统计方案随初步结果扩展。医生参与集中在必要的临床定义与歧义，不作为全部原型工作的前置条件。

## 角色

- A：本地研究总控，维护协议与汇报，汇总 B/C 状态。
- B：Larry 原型实现，复用既有代码，保存可重跑配置。
- C：Larry 评测，管理评分、参考答案和匿名错误分析。
- DSH：用户在 Windows 使用的讨论与读论文工具，直接读取本地交接目录；属于辅助讨论入口。

研究用模型本身的供应商、授权范围与预算尚待具体执行前落实。使用 Codex/DSH 写代码，不等于已确定论文实验必须采用相同模型。
